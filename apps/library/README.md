# Design Library app

Open the repository root `index.html` directly. Its assets live here; reusable
foundations and components live under `packages/`. No installation or build needed.

Choose an identity, expression, and accent. Browse or filter 67 component entries,
interact with examples, expand their HTML, and copy snippets. Theme application
is centralized in `renderTheme()`; markup and behavior are shared across systems.
Original standalone showcases remain available through the source link.
