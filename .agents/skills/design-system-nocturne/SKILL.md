# Apply Nocturne / The Dreamer

Read [the Nocturne reference](../../../docs/design/systems/NOCTURNE_DESIGN_SPEC.md)
and [the system/API map](../../../docs/design/DESIGN_SYSTEMS.md). Preserve the
shared charter's semantic and conditional-approval boundaries.

Use `system: 'nocturne'`; `light` means Daydream, `dark` means Nebula. Accent
indices are 0 Ultraviolet/Iris, 1 Orchid/Magenta, 2 Iris/Cool Refraction. They are
coordinated studies within one ultraviolet-centered identity, not separate brands.

Carry depth through opaque planes, relative elevation, selective refractive edges,
inset fields and floating tab surfaces. Keep dense tables, forms, errors and
notifications quieter than showcase panels. Text and targets stay stable; do not
refract through text, glow every edge or require cosmic illustrations.
Use layered icon geometry and short fluid spatial transitions with static reduced-
motion equivalents. Critical feedback must not wait for decorative motion.

Use exported React primitives and shared root theme/data-slot styles; do not fix
only the catalog gradient. Preserve portals, handlers, validation/recovery,
keyboard focus and AI transport. Native styles use a separate adapter contract.

Review both expressions and affected spectra in dense and spacious contexts.
Keep values exploratory, synchronize affected design references, and state the
checks performed rather than claiming unmeasured accessibility.
